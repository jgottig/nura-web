# NURA · Nutrición para mascotas

Sitio web de NURA, alimento natural para perros (Rosario y Gran Rosario).

- `index.html`: landing
- `producto.html?p=vacuna|pollo|cerdo`: detalle de cada receta
- `js/productos.js`: datos editables (WhatsApp, Instagram, recetas, tabla nutricional, porciones)

Sitio estático (HTML/CSS/JS), sin build. Se publica con GitHub Pages desde `main`.
